# Cohere Rerank功能使用指南

## 重排序功能概述

重排序（Reranking）是提高RAG系统检索质量的重要技术，通过对初步检索结果进行二次评估和排序，可以显著提高最终回答的准确性和相关性。本项目集成了Cohere Rerank服务，它是一个专门用于文档重排序的API服务。

**特别说明**: 重排序功能设计为可与任何检索模式（向量检索、BM25检索、混合检索）结合使用，作为检索后的增强步骤，而不是一种独立的检索模式。推荐的使用方式是在混合检索基础上启用重排序功能。

## 配置步骤

1. **获取Cohere API密钥**
   - 访问 [Cohere官网](https://cohere.ai/) 注册账号
   - 在控制台中创建API密钥

2. **配置环境变量**
   - 在`.env`文件中添加以下配置：
     ```
     COHERE_API_KEY=your_cohere_api_key_here
     ```

3. **安装依赖**
   - 确保已安装所需的依赖：
     ```bash
     pip install cohere llama-index-postprocessor-cohere-rerank
     ```

## 使用方法

### API调用

发送POST请求到 `/api/chat` 端点，并指定启用重排序：

```json
{
  "query": "你的查询内容",
  "use_rerank": true,
  "rerank_language": "auto"
}
```

参数说明：
- `query`: 用户查询文本（必需）
- `use_rerank`: 是否使用重排序，设置为true启用重排序功能
- `rerank_language`: 重排序使用的语言模型，支持以下选项：
  - `auto`: 自动检测查询语言（默认），中文查询使用多语言模型，英文查询使用英文模型
  - `english`: 强制使用英文模型（rerank-english-v3.0）
  - `multilingual`: 强制使用多语言模型（rerank-multilingual-v3.0），支持中文等多种语言

### 测试重排序功能

使用提供的测试脚本测试重排序功能：

```bash
python test_rerank.py
```

该脚本将对比不同配置的性能和回答质量：
1. 仅混合检索（无重排序）
2. 混合检索+英文重排序
3. 混合检索+多语言重排序

## 工作原理

1. **初始检索**：首先使用混合检索模式获取较大数量（通常为20个）的候选文档
2. **重排序处理**：Cohere Rerank对这些候选文档进行精细评估，计算它们与查询的真实相关性
3. **筛选结果**：保留相关性最高的top_n个文档（默认为5个）
4. **生成答案**：使用筛选后的文档生成最终回答

## 性能考虑

- **API调用成本**：每次使用Cohere Rerank会产生API调用费用，根据您的使用量定价
- **延迟增加**：引入重排序会增加约100-300ms的延迟，视文档数量和长度而定
- **效果提升**：根据测试，重排序可以使RAG系统检索准确率提高10-30%

## 技术细节

Cohere的重排序模型基于先进的文本相关性评估技术，能够：

1. 理解文档与查询之间的语义关系
2. 识别文档中与查询相关的关键信息
3. 评估文档回答查询的完整性和准确性
4. 考虑查询意图与文档内容的匹配度

### 多语言支持

Cohere提供了两种主要的重排序模型：

1. **英文模型 (rerank-english-v3.0)**：
   - 专为英文内容优化，提供最佳的英文重排序效果
   - 性能更好，响应更快

2. **多语言模型 (rerank-multilingual-v2.0)**：
   - 支持多种语言，包括中文、日文、韩文等
   - 适合处理非英文查询和内容
   - 可能响应时间略长于英文模型

系统默认使用"自动检测"模式，会根据查询文本中是否包含中文字符自动选择合适的模型。对于混合语言查询，建议使用多语言模型。

## 最佳实践

- **推荐配置**: 混合检索 + Cohere重排序提供了最佳的查询效果
- **检索数量**: 初始检索数量设置为20个文档是一个良好的平衡点
- **性能优化**: 对于简单查询可以不启用重排序，仅对复杂查询启用以节省API调用
- **语言选择**: 
  - 纯英文查询: 使用英文模型获得最佳效果和性能
  - 中文查询: 使用多语言模型获得更好的理解
  - 混合语言: 使用多语言模型
  - 不确定: 使用自动检测模式

## 故障排除

如果遇到以下问题：

1. **"Cohere API密钥未设置"错误**
   - 检查`.env`文件中是否正确设置了`COHERE_API_KEY`
   - 确认服务器启动时已正确加载环境变量

2. **重排序结果不理想**
   - 尝试增加初始检索的文档数量（`similarity_top_k`）
   - 调整最终保留的文档数量（`top_n`）
   - Cohere会自动选择适合的重排序模型
